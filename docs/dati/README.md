# Dati

- `riscaldamento-stretching.json`: 145 esercizi di riscaldamento e stretching (nomi e testi in italiano), forniti dall'utente e derivati da [free-exercise-db](https://github.com/yuhonas/free-exercise-db), licenza Unlicense (pubblico dominio). Il file resta invariato; istruzioni e URL delle immagini non sono usati dal pannello.
- Il pannello usa la versione compatta `src/data/catalogo-riscaldamento.json`: dopo ogni modifica alla sorgente, rigenerarla con `node scripts/catalogo-riscaldamento.js` e committarla (un test verifica che sia aggiornata).
